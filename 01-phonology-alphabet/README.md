# 01 · 语音和字母学习 (Phonologie & Alphabet)

> CP1 · 语音字母阶段。目标:拿到任何一个德语词,能自洽地读出来、写出它的字母,并听辨出长短元音、变元音、特殊辅音。

---

## 1. 字母表 (Das Alphabet)

德语 26 个拉丁字母 + 4 个特殊字母 = **30 个书写单位**。

### 1.1 标准拉丁字母 (26)

| 字母 | 名称 | 字母 | 名称 | 字母 | 名称 |
|---|---|---|---|---|---|
| A a | **a** | J j | **jot** | S s | **es** |
| B b | **be** | K k | **ka** | T t | **te** |
| C c | **tse** | L l | **el** | U u | **u** |
| D d | **de** | M m | **em** | V v | **fau** |
| E e | **e** | N n | **en** | W w | **we** |
| F f | **ef** | O o | **o** | X x | **iks** |
| G g | **ge** | P p | **pe** | Y y | **ypsilon** |
| H h | **ha** | Q q | **ku** | Z z | **tset** |
| I i | **i** | R r | **er** | | |

> ⚠️ 跟英语读音完全不同的几个:**J=jot**(/jɔt/,不是 jay)、**V=fau**(/faʊ/,读 f 音)、**W=we**(/veː/,读 v 音)、**Z=tset**(/t͡sɛt/,带 ts)、**Y=ypsilon**。

### 1.2 四个特殊字母 (Umlaute + Eszett)

| 字母 | 名称 | 本质 |
|---|---|---|
| **Ä ä** | Umlaut-a | a 的前圆唇化,e/a 之间 |
| **Ö ö** | Umlaut-o | o 的前圆唇化 |
| **Ü ü** | Umlaut-u | u 的前圆唇化 |
| **ß** | Eszett / scharfes S | 无大写(1996 正字前),2017 起大写为 **ẞ** |

- **变元音替代写法**(无德语键盘时):`ä→ae, ö→oe, ü→ue, ß→ss`。注意:这是**拼写改变**,不是“忽略”。`Straße` 的 `ß` 和 `ss` 是正字不同的音位标记。
- `ß` **只在长元音或双元音之后**出现(`Straße, beißen`),`ss` 在短元音之后(`Wasser, muss`)。
- 瑞士不用 `ß`,一律写 `ss`。

## 2. 元音系统 (Vokale)

### 2.1 单元音的长短对立

德语每个元音字母都有**长 / 短**两套,且 **a o u ä ö ü** 还有**松紧**差别。**长短是音位的**(能区分词义),这是初学者最容易漏的。

| 字母 | 长 | 例 | 短 | 例 |
|---|---|---|---|---|
| a | [aː] | **a**ber, Tat | [a] | **a**ll, Mann |
| e | [eː] | L**e**ben, s**e**hr | [ɛ] | W**e**lt, n**e**nnen |
| i | [iː] | m**ie**ne, w**ie** | [ɪ] | **i**n, B**i**ld |
| o | [oː] | S**o**hn, Gr**o**ß | [ɔ] | S**o**nne, v**o**n |
| u | [uː] | B**u**ch, **U**hr | [ʊ] | **u**nd, M**u**tter |

> 拼写判断长短的规律(强,但非 100%):
> - **双写元音 / 元音 + h → 长**:`Aal, Meer, Boot, Uhr`,以及 `gehen, nehmen, fahren`。
> - **单元音 + 双辅音 → 短**:`Mann, Bett, Wasser, muss`。
> - **单元音 + 单辅音 + 元音 → 长(开音节)**:`le-ben, Ta-ge, Bo-den`。

### 2.2 弱化元音 [ə] 和 [ɐ]

- 词尾 **-e** 弱化为 **[ə]**(schwa):`Liebe = [ˈliːbə]`。口语里常**完全不发音**:`haben → ham`。
- **-er** 弱化为 **[ɐ]**(a-schwa,听起来像很轻的 a):`Lehrer = [ˈleːʁɐ]`。这跟英语 `-er` 不同。

### 2.3 变元音的实际音值

| 字母 | 长 | 短 | 例 |
|---|---|---|---|
| ä | [ɛː] | [ɛ] | **Ä**rzte, B**ä**r / M**ä**dchen |
| ö | [øː] | [œ] | **S**öhne→长; L**ö**ffel→短 |
| ü | [yː] | [ʏ] | **ü**ber→长; F**ü**nf→短 |

> 发不出 `ö/ü`?**技巧**:
> - `ö` = 先发 [e],保持舌头,**圆唇**。
> - `ü` = 先发 [i],保持舌头,**圆唇**。

### 2.4 双元音 (Diphthonge)

| 写法 | 音值 | 例 |
|---|---|---|
| **ei / ai / ey / ay** | [aɪ] | mein, Mai, Meyer, Bayern |
| **au** | [aʊ] | Baum, Haus |
| **eu / äu** | [ɔɪ] | Deutsch, Häuser |

> 只有这 **3 个真正的双元音**。`ie` 不是双元音,是**长 i** [iː](`Liebe, Spiel`)。

## 3. 辅音系统 (Konsonanten)

### 3.1 几个“长得不像,但其实要记住”的对应

| 写法 | 音值 | 注意 |
|---|---|---|
| **w** | [v] | 德语 w = 英语 v。**W**agen = [ˈvaːɡn̩] |
| **v** | [f] 多数 / [v] 外来词 | **V**ater = [ˈfaːtɐ]; **V**ase = [ˈvaːzə] |
| **s** (元音前) | [z] | **S**ee, **s**ie = 浊 s |
| **s** (其它) | [s] | Da**s**, Bu**s** = 清 s |
| **ß** | [s] | 永远清 s,**只在长元音/双元音后** |
| **ss** | [s] | 永远清 s,**只在短元音后** |
| **z / tz** | [t͡s] | **Z**eit [t͡saɪ̯t], Sat**z** = 一次发 ts |
| **j** | [j] | **j**a [jaː],类似英语 y |
| **r** | [ʁ] 词首/颤;[ɐ] 词尾弱化 | **R**ot 颤,**der** → [deːɐ] |
| **ch** (a/o/u/au 后) | [x] | ma**ch**en, Bu**ch**, lau**ch**t |
| **ch** (其它元音后/词首) | [ç] | i**ch**, **ch**inesisch, L**ö**ffel 后面 ch |
| **sch** | [ʃ] | **Sch**ule = 英语 sh |
| **sp / st** (词首/音节首) | [ʃp / ʃt] | **Sp**iel = [ʃpiːl], **St**adt = [ʃtat] |
| **sp / st** (词中/词尾) | [sp / st] | We**sp**e, Fe**st** |
| **pf** | [p͡f] | A**pf**el, **Pf**erd |
| **qu** | [kv] | **Qu**elle = [ˈkvɛlə] |
| **ng** | [ŋ] | si**ng**en, 类似英语 sing |
| **nk** | [ŋk] | si**nk**en, 发完整 ŋk |

### 3.2 词尾清化 (Auslautverhärtung) —— 关键规则

**所有浊辅音 b d g v z 在音节/词尾 → 变成对应的清辅音 p t f f s。**

| 写 | 读 |
|---|---|
| Hub**b** | [hʊp] |
| Han**d** | [hant] |
| Ta**g** | [taːk] |
| Hau**s** | [haʊs] |
| Bri**e**f(e) | 词尾 f 读 [f];但变格后 `Briefes` 又回 [v] |

> 这就是为什么 `Hund`(狗)和 `Hunt`(狩猎古词)同音,为什么 `Rad`(轮)和 `Rat`(建议)**同音** [ʁaːt]。背单词时,**记拼写 + 变格后的发音**,别只记词尾。

### 3.3 -ig 词尾

- 标准:`-ig` 词尾读 **[ɪç]**(不是 [ɪk]):`fertig = [ˈfɛʁtɪç]`, `lustig`。
- 南德/奥:-ig 可读 [ɪk]。
- 外来词如 `mystisch` 不适用。

## 4. 重音与节奏 (Wortakzent)

- **第一个音节重读**(日耳曼原生词):**LE**-ben, **WAS**-ser, **SCHU**-le。
- **例外**:
  - **be- ge- er- ver- zer- ent- emp- miss-** 等不可分前缀词:重音在**前缀之后**:be-KOM-men, ver-SUCH-en。
  - 外来词:常按原语重音:Pro-fes-**SOR**, De-mok-**RA**-tie。
  - 复合词:重音在**第一个成分**:**AU**-to-bahn, **KIND**-er-garten。
- **-tion / -um / -ik** 等外来后缀重读该音节:In-for-ma-**TION**, Mu-**SIK**(本地后缀如 -schaft 不重读:**WIS**-sen-schaft)。

## 6. 自测 (Selbsttest)

读出/拼写下面词,然后对照答案。

1. `Brötchen`(小面包)
2. `Zusammen`(一起)
3. `Tschüss`(拜拜)
4. `Fragezeichen`(问号)
5. `Schwierig`(困难的)

**答案速查**:
1. [ˈbʁœtçən] — ö 短 [œ],ch 在 ö 后是 [ç]
2. [t͡suˈzamən] — z=ts,s 在 a 前浊 [z],重音在 sam
3. [t͡ʃʏs] — ü 短 [ʏ],注意拼写是 ss 不是 ß(因为短元音后)
4. [ˈfʁaːɡəˌt͡saɪ̯çn̩] — z=ts,eu=[ɔɪ]
5. [ˈʃviːʁɪç] — ig 词尾 [ɪç]
