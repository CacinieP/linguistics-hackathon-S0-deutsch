# 02 · 自由语素 · 功能词 (Funktionswörter)

> 功能词(Funktionswort / Grammatisches Wort)自身**没有实在词义**,只表达语法关系。
> 它们都是**自由语素**(能独立成词),但不同于词根——它们**封闭、有限、高频**,是句子的「关节」。

---

## 1. 功能词 vs 实义词

| | 实义词(Lexikalisches Wort) | 功能词(Funktionswort) |
|---|---|---|
| 例 | Haus, gehen, schön | der, in, und, ich |
| 数量 | 开放,无限 | 封闭,有限(~200) |
| 作用 | 承载词义 | 表达语法关系 |
| 变化 | 可派生/复合 | 形态固定 |
| 学习 | 逐个记 + 拆语素 | 整体记 + 学搭配 |

> 功能词虽然「无义」,但**决定了句子的格、时态、逻辑**——错了它们,实词再对句子也错。

---

## 2. 功能词的子分类

```
功能词 Funktionswort
├── 冠词 Artikel
│   ├── 定冠词 (der/die/das)
│   ├── 不定冠词 (ein/eine)
│   ├── 否定冠词 (kein)
│   └── 物主冠词 (mein/dein…)
├── 代词 Pronomen
│   ├── 人称 (ich/du/er…)
│   ├── 反身 (sich)
│   ├── 指示 (dieser/jener)
│   ├── 关系 (der/die/das 作关系代词)
│   ├── 疑问 (wer/was/welcher)
│   └── 不定 (man/jemand/niemand)
├── 介词 Präposition(管格!)
│   ├── +Akk: durch/für/ohne/um/gegen…
│   ├── +Dat: aus/bei/mit/nach/seit/von/zu…
│   ├── 双向 (Wechselpräp.): in/an/auf/über/unter…
│   └── +Gen: wegen/während/trotz…
├── 连词 Konjunktion
│   ├── 并列 (und/aber/oder/sondern/denn)
│   └── 从属 (weil/dass/wenn/als/ob/während…)
├── 情态词 Modalpartikel (ja/doch/mal/denn/halt/bloß)
└── 助动词 Hilfsverb (haben/sein/werden)
```

---

## 3. 冠词(Artikel)按 CEFR

> 冠词本质是**格/性/数的标记**,形态见 `06-inflectional.md`。这里只列「词」本身。

### 3.1 [A1] 定 / 不定 / 否定 / 物主

| 类型 | 词 | 说明 |
|---|---|---|
| 定冠词 | der / die / das / die(Pl.) | 标「已知/特定」 |
| 不定冠词 | ein / eine | 标「任意一个」,无复数 |
| 否定冠词 | kein / keine / keine(Pl.) | = ein 的否定,有复数 |
| 物主冠词 | mein/dein/sein/ihr/unser/euer/Ihr/Ihnen | 变格同 kein |

### 3.2 [A2] 指示冠词

| 词 | 义 |
|---|---|
| dieser / diese / dieses | 这个 |
| jener / jene / jenes | 那个 |
| jeder / jede / jedes | 每个 |
| mancher | 好些个 |
| solcher | 这样的 |

### 3.3 [B1] 关系代词化的 der

`der/die/das` 在关系从句中作**关系代词**:`der Mann, der dort steht`(站在那儿的男人)。

---

## 4. 代词(Pronomen)按 CEFR

### 4.1 [A1] 人称代词

| Nom | Akk | Dat |
|---|---|---|
| ich | mich | mir |
| du | dich | dir |
| er / sie / es | ihn / sie / es | ihm / ihr / ihm |
| wir | uns | uns |
| ihr | euch | euch |
| sie / Sie | sie / Sie | ihnen / Ihnen |

### 4.2 [A1] 反身代词 `sich`

三单/三复 = `sich`:`sich freuen, sich waschen, sich ansehen`。

### 4.3 [A2] 疑问代词

| 词 | 问 |
|---|---|
| wer | 谁(Nom) |
| wen / wem | 谁(Akk/Dat) |
| was | 什么 |
| welcher / welche / welches | 哪个 |
| wessen | 谁的(Gen) |
| wo / wohin / woher | 哪里/去哪/从哪 |

### 4.4 [A2] 不定代词

| 词 | 义 |
|---|---|
| man | 人们(泛指,只用三单) |
| jemand | 某人 |
| niemand | 没人 |
| etwas / nichts | 某物/无物 |
| alle / alles | 所有 |
| viele / wenige | 许多/少数 |

### 4.5 [B1] 关系代词

`der/die/das`(变格)、`wer`(泛指先行)、`wo`(地点关系)。

## 5. 介词(Präposition)—— 按格分组

> **介词决定后面名词的格**,这是功能词里最该死记硬背的一组。

### 5.1 [A1] + Akkusativ(只带宾格)

| 介词 | 义 | 例 |
|---|---|---|
| durch | 通过 | durch den Park |
| für | 为了 | für dich |
| gegen | 反对/大约 | gegen den Strom; gegen 8 Uhr |
| ohne | 没有 | ohne mich |
| um | 围绕/在…时 | um den Tisch; um 8 Uhr |
| entlang | 沿着(后置时 +Akk) | die Straße entlang |

### 5.2 [A1] + Dativ(只带与格)

| 介词 | 义 | 例 |
|---|---|---|
| aus | 从…出/由…制 | aus Deutschland; aus Holz |
| bei | 在…旁/在…时 | bei mir; bei Nacht |
| mit | 和/用 | mit dir; mit dem Auto |
| nach | 去/在…后 | nach Berlin; nach der Arbeit |
| seit | 自从 | seit zwei Jahren |
| von | 从/…的 | von dir; der Hund von Maria |
| zu | 去/在…旁 | zu dir; zum Arzt |
| gegenüber | 在…对面(可后置) | dir gegenüber |

### 5.3 [A1/A2] 双向介词(Wechselpräpositionen)

> 同一介词,**位移→Akk,位置→Dat**(「动九静三」)。

`in / an / auf / über / unter / vor / hinter / neben / zwischen`

- Ich gehe **in** die Schule.(Akk,位移)
- Ich bin **in** der Schule.(Dat,位置)

### 5.4 [B1] + Genitiv

| 介词 | 义 |
|---|---|
| wegen | 因为 |
| während | 在…期间 |
| trotz | 尽管 |
| statt / anstatt | 代替 |
| innerhalb / außerhalb | 在…内/外 |
| aufgrund | 由于 |
| mangels | 缺乏 |

### 5.5 [B2] 介词与动名词固定搭配

`Interesse an +Dat`(对…的兴趣)、`Recht auf +Akk`(对…的权利)、`Fähigkeit zu +Dat`(…的能力)。这些要连介词一起背。

## 6. 连词(Konjunktion)—— 按句法位置

### 6.1 [A1] 并列连词(占位 0,不改语序)

| 词 | 义 |
|---|---|
| und | 和 |
| aber | 但是 |
| oder | 或者 |
| denn | 因为 |
| sondern | 而是(前有否定) |

### 6.2 [A2] 从属连词(占末位,动词尾置)

| 词 | 义 |
|---|---|
| weil | 因为 |
| dass | that |
| wenn | 如果/当 |
| als | 当(过去)/比 |
| ob | 是否 |
| obwohl | 虽然 [B1] |
| während | 而/在…期间 [B1] |
| bevor / nachdem | 在…前/后 [B1] |
| damit | 以便 [B1] |
| falls | 万一 [B2] |

### 6.3 [B1] 占位连词(占第一位,动词第二位)

| 词 | 义 |
|---|---|
| deshalb | 因此 |
| trotzdem | 尽管如此 |
| dann | 然后 |
| sonst | 否则 |
| außerdem | 此外 |
| außerdem | 此外 |

> 这类词**本身是副词性**,占第一位,主句动词在第二位(V2),如 `Ich war krank, deshalb **bleibe** ich zu Hause.`

---

## 7. 情态小品词(Modalpartikel)—— [B1/B2]

> 这类词**无法直译**,只调节语气。德语口语的灵魂。

| 词 | 功能 | 例 |
|---|---|---|
| ja | 你知道的/强调 | Er ist ja krank.(他不是病了嘛) |
| doch | 反驳/确信 | Komm doch mit!(就来嘛!) |
| mal | 弱化命令 | Warte mal.(等等) |
| denn | 追问原因 | Was machst du denn?(你到底在做啥) |
| halt / eben | 无奈接受 | So ist es halt.(就这样呗) |
| bloß / nur | 强调/警告 | Pass bloß auf!(小心点!) |
| eigentlich | 转话题/探询 | Was willst du eigentlich?(你到底想要啥) |

> 小品词常**重叠**:`Das ist ja wohl ein Witz!`(这也算笑话!)

---

## 8. 助动词(Hilfsverb)

| 词 | 功能 | CEFR |
|---|---|---|
| haben | Perfekt 助动词(多数) | [A1] |
| sein | Perfekt 助动词(位移/状态)+ 被动 Zustandspassiv | [A1] |
| werden | Futur 助动词 + 被动 Vorgangspassiv | [A1] |

> 助动词本身是**自由语素 + 不规则变位**(见 `06-inflectional.md`)。

---

## 9. 小结

- 冠词/代词 = **格的标记**,优先和名词一起记。
- 介词 = **格的开关**,必须连格一起背(+Akk / +Dat / +Gen / 双向)。
- 连词 = **语序的开关**(并列 0 位 / 从属末位 / 占位第 1)。
- 小品词 = **口语的灵魂**,无义但定调。
- 助动词 = **时态/语态的胶水**。

功能词虽然封闭、有限,但每一个都「四两拨千斤」。
