# 03 · 派生前缀 (Derivationspräfixe)

> 前缀加在词根**前面**,改变或微调词义,**不改词性**(动词前缀 → 还是动词)。
> 德语前缀分两大阵营:**不可分前缀**(重音在词干)+ **可分前缀**(重音在前缀)+ **外来前缀**。

---

## 1. 前缀的三大阵营

```
派生前缀 Präfix
├── 不可分前缀 untrennbare Präfixe (重音在词干,过去分词无 ge-)
│   └── be- ge- er- ver- zer- ent- emp- miss-
├── 可分前缀 trennbare Präfixe (重音在前缀,变位时前缀到句尾)
│   └── ab- an- auf- aus- ein- mit- nach- vor- zu- zurück- zusammen- …
└── 外来前缀 fremde Präfixe (多来自拉丁/希腊)
    └── de(s)- dis-/des- in-/il-/im- re- ko-/kor-/kom- prä- pro- …
```

> 少数前缀**两可**(`durch-, über-, um-, unter-, wider-, wiederhol-`),靠**重音**判可分/不可分,且意义不同:
> - `übersétzen`(可分,渡河)vs `übersétzen`… 实例:`umármen`(可分,拥抱)vs `umármen`… 见 §5。

---

## 2. 不可分前缀(untrennbare Präfixe)[A2–B2]

> 特征:**重音在词干**;过去分词**不加 ge-**(如 `verstehen → verstanden`)。

### 2.1 `be-` [A2] —— 使及物化 / 施加于

| 词根 + be- | 义 | 派生 |
|---|---|---|
| `wohnen` → `bewohnen` | 居住于 | Bewohner, bewohnbar |
| `suchen` → `besuchen` | 拜访 | Besuch |
| `nutzen` → `benutzen` | 使用 | Benutzung |
| `deuten` → `bedeuten` | 意味 | Bedeutung, bedeutend |
| `grißen`→`begrüßen` | 问候 | Begrüßung |
| `legen`→`belegen` | 占据/铺 | Beleg, belegbar |

**功能**:`be-` 常把不及物动词变及物,或把名词「动词化施加」:`Bild → bilden, Grenze → begrenzen`。

### 2.2 `ge-` [A2] —— 过去/集合(弱标记)

- 古集合义:`Spiel → Gespräch`(集合名词)。
- 多数 `ge-` 是**屈折标记(过去分词)**,不是派生前缀:`ge-macht, ge-sehen`。
- 派生 `ge-` 词:`gebrauchen`(使用)、`gefallen`(使喜欢)、`gehören`(属于)。

### 2.3 `er-` [B1] —— 获得 / 致使 / 达到

| 词根 + er- | 义 | CEFR |
|---|---|---|
| `fahren` → `erfahren` | 经历/得知 | [B1] |
| `zählen` → `erzählen` | 讲述 | [B1] |
| `klären` → `erklären` | 解释 | [B1] |
| `finden` → `erfinden` | 发明 | [B2] |
| `leben` → `erleben` | 经历 | [B1] |
| `warten`→`erwarten` | 期待 | [B1] |
| `finden`→`erfinden` | 发明 | [B2] |
| `kennen`→`erkennen` | 认出 | [B2] |
| `folg-`→`erfolgen` | 实现/发生 | [B1](sich ergeben 义) |
| 形容词→`er-`:kalt→`erkalten`, blind→`erblinden` | 致使(变…) | [B2] |

**功能**:常表「达到某状态」或「获得」,名词化多带 `-ung`:Erfahrung, Erklärung, Erfindung。

### 2.4 `ver-` [A2–B1] —— 最强多义前缀

| 功能 | 例 |
|---|---|
| 强化/转变 | `bessern → verbessern`(改善), `größern → vergrößern` |
| 错误/失败 | `sehen → versehen`(搞错), `sprechen → versprechen`(错说/承诺) |
| 消耗/失去 | `lieren→verlieren`(失), `gehen→vergehen`(消逝) |
| 使成/覆盖 | `decken → verdecken`, `binden → verbinden`(连接) |
| 反复/彻底 | `suchen → versuchen`(尝试) |

> `ver-` 是德语**最高频、最多义**的前缀,意义要结合词根学,但多数落在「转变/错误/彻底」三义。

### 2.5 `zer-` [B1] —— 分裂/破坏

| 词根 + zer- | 义 |
|---|---|
| `brechen → zerbrechen` | 打碎 |
| `stören → zerstören` | 毁坏 |
| `fallen → zerfallen` | 崩解 |
| `schneiden → zerschneiden` | 切开 |
| `legen → zerlegen` | 拆解 |

**功能**:强「破坏/分解」义,所造词多为及物。

### 2.6 `ent-` [B1] —— 去除 / 反向 / 开始

| 词根 + ent- | 义 |
|---|---|
| `decken → entdecken` | 发现(揭去) |
| `gehen → entstehen` | 产生 |
| `täuschen → enterält…` | (注意形近) |
| `fern → entfernen` | 移开 |
| `schuldigen → entschuldigen` | 原谅 |
| `scheiden → entscheiden` | 决定 |
| `fliehen → entfliehen` | 逃离 |
| 形容词→ent-:gifitg→`entgiften`(解毒) | 去除 |

**功能**:相当于英语 `dis-/de-`——「反向/去除/开始」。

### 2.7 `emp-` [B2] —— `ent-` 在 `f/pf` 前的变体

- `fangen → empfangen`(接收)
- `fehlen → empfehlen`(推荐)
- `finden`→(形近)无

**功能**:`emp-` = `ent-` 的**语素变体 Allomorph**(在 f/pf 前 assimilation)。

### 2.8 `miss-` [B2] —— 错误/否定

| 词根 + miss- | 义 |
|---|---|
| `verstehen → missverstehen` | 误解 |
| `achten → missachten` | 蔑视 |
| `lingen → misslingen` | 失败 |
| `trauen → misstrauen` | 不信任 |
| 形容词/名词:Missverständnis(误解) | |

**功能**:相当于英语 `mis-`,表「错/坏/否定」。

## 3. 可分前缀(trennbare Präfixe)[A1–B1]

> 特征:**重音在前缀**;变位时前缀跑到句尾;过去分词 `ge-` 插中间(`aufstehen → aufgestanden`)。

### 3.1 方向/位移类 [A1]

| 前缀 | 义 | 例 |
|---|---|---|
| `ab-` | 离开/向下 | abfahren(驶离), abnehmen(取下) |
| `an-` | 接触/朝向 | ankommen(到达), anmachen(开/打开) |
| `auf-` | 向上/开启 | aufstehen(起立), aufmachen(打开) |
| `aus-` | 出/完成 | ausgehen(外出), ausmachen(关掉) |
| `ein-` | 进入 | einkaufen(购物), einsteigen(上车) |
| `nach-` | 跟随/之后 | nach Hause(短语), nachkommen(跟上) |
| `vor-` | 向前/提前 | vorstellen(介绍), vorlesen(朗读) |
| `zu-` | 向/关闭 | zumachen(关), zuhören(倾听) |
| `mit-` | 一起 | mitkommen(同来), mitnehmen(带走) |
| `zurück-` | 回 | zurückkommen(回来) |
| `zusammen-` | 一起 | zusammenarbeiten(合作) |
| `hinaus-/heraus-` | 出去/出来 | hinausgehen |

### 3.2 状态/结果类 [A2]

| 前缀 | 义 | 例 |
|---|---|---|
| `auf-` | 开启 | aufschließen(开锁) |
| `an-` | 开启(电/光) | anmachen, anknipsen |
| `fern-` | 远(电视) | fernsehen(看电视) |
| `kennen-` | 认识 | kennenlernen(结识) |
| `fest-` | 固定 | feststellen(确定), festhalten(握住) |
| `frei-` | 释放 | freilassen, freigeben |
| `statt-` | 举行 | stattfinden(举行) |
| `teil-` | 参加 | teilnehmen(参加) |
| `statt-` | 代替 | vertreten…(异根) |

---

## 4. 外来前缀(fremde Präfixe)[B1–C2]

> 多来自拉丁/希腊,常连词根一起借入,重音多在词根。

### 4.1 否定/反转类

| 前缀 | 义 | 例 | CEFR |
|---|---|---|---|
| `de(s)-` | 去/降 | dezentral, destillieren | [C1] |
| `dis-/des-` | 否定 | diskont…, Disharmonie | [C1] |
| `in-/il-/im-/ir-` | 不(形容词) | instabil, illegal, unmöglich… 实为 in- | [B2] |
| `a-/an-` | 无(希) | anonym, asymmetrisch | [C1] |

### 4.2 方向/关系类

| 前缀 | 义 | 例 |
|---|---|---|
| `re-` | 再/回 | reorganisieren, reparieren, rezitieren |
| `prä-` | 前 | präzise, präventiv |
| `pro-` | 向前/支持 | produzieren, Pro-Kontra |
| `inter-` | 之间 | international, interviewen |
| `trans-` | 跨越 | transportieren, transatlantisch |
| `sub-` | 下/次 | Substanz, subtrahieren |
| `super-` | 上/超 | Supermarkt, super |
| `ko-/kor-/kom-` | 共同 | kooperieren, korrespondieren, kompliziert |
| `ad-/ak-/ap-` | 朝向 | akzeptieren, adaptieren |

### 4.3 名词性外来前缀

| 前缀 | 义 | 例 |
|---|---|---|
| `anti-` | 反 | Antibiotikum |
| `auto-` | 自 | Automat, autonom |
| `bio-` | 生物 | Biologie |
| `geo-` | 地 | Geographie |
| `tele-` | 远 | Telefon, Teleskop |
| `philo-` | 爱 | Philosophie |
| `micro-/macro-` | 微/宏 | Mikroskop, Makroökonomie |

## 5. 两可前缀(双重前缀 Doppelpräfix)[B1–B2]

> 同形前缀,**重音决定可分/不可分**,意义随之不同。
> 规则:**重音落在前缀 → 可分(前缀跑到句尾);重音落在词干 → 不可分**。

| 不定式 | 重音在哪 | 义 | 可分? |
|---|---|---|---|
| **`um`armen** | 前缀 `um-` | 拥抱 | 可分 |
| um**arm**en | 词干 | 围绕(罕) | 不可分 |
| **`durch`sehen** | 前缀 `durch-` | 看穿/看透 | 可分 |
| durch**seh**en | 词干 | 审阅(文件) | 不可分 |
| **`über`setzen** | 前缀 `über-` | 渡过(河) | 可分 |
| über**setz**en | 词干 | 翻译 | 不可分 |
| **`wieder`holen** | 前缀 `wieder-` | 取回 | 可分 |
| wieder**hol**en | 词干 | 重复 | 不可分 |
| **`um`stellen** | 前缀 `um-` | 改变位置 | 可分 |
| um**stell**en | 词干 | 包围 | 不可分 |

> 听音辨义:同一个词,重音挪一格,意思就变。这是德语最微妙的前缀现象。

---

## 6. 前缀的语法效应速查

| 前缀类型 | 重音 | 过去分词 | 句中位置 | 例 |
|---|---|---|---|---|
| 不可分 | 词干 | **无 ge-** | 不分开 | `Ich verstehe das.` / `verstanden` |
| 可分 | 前缀 | **ge- 插中间** | 前缀→句尾 | `Ich rufe dich an.` / `angerufen` |
| 外来 | 词根 | 多 `~iert` | 不分开 | `Ich studiere.` / `studiert` |

---

## 7. 小结

- 不可分前缀 = **意义改造器**(ver-/er-/be-/zer-/ent-…)。
- 可分前缀 = **方向/状态标记**(ab-/an-/auf-/aus-…),A1 就大量出现。
- 外来前缀 = **拉丁/希腊借词的零件**,形态规整。
- 两可前缀 = **听音辨义**,靠重音判可分。
- 前缀**不改词性**(动词根 → 动词),改词性靠**后缀**(见 `04-derivational-suffixes.md`)。
