# 04 · 派生后缀 (Derivationssuffixe)

> 后缀加在词根**后面**,改变**词性**(动→名 / 形→名 / 名→形…),也常带语义色彩。
> 与前缀不同,**后缀决定词性**,因此是「猜词性、猜词义」最有规律的工具。

---

## 1. 后缀的功能分类

```
派生后缀 Suffix
├── 产出名词 Nomen-schaffend
│   ├── ← 动词: -ung / -tion / -ei / -en
│   ├── ← 形容词: -heit / -keit / -igkeit
│   └── ← 名词/其它: -er / -ist / -in / -chen / -lein
├── 产出形容词 Adjektiv-schaffend
│   ├── -ig / -lich / -isch / -bar / -haft / -los / -sam
│   └── ← 动词: -bar(可…的) / -end(分词化)
├── 产出动词 Verb-schaffend
│   └── -ieren(外来)/ -eln / -ern
└── 产出副词 Adverb-schaffend
    └── -s / -erweise
```

---

## 2. 产出**阴性名词**的后缀

### 2.1 `-ung` [A2] —— 动词→抽象阴性名词(德语最强后缀)

> **任何动词**词干 + ung → 阴性抽象名词,义为「该动作的过程/结果」。

| 动词 | 名词 | 义 |
|---|---|---|
| `lehren` | **die Lehre**… 实为 -e(见下);正确:`die Lernung`? | (注意:lernen 不成名词化 -ung) |
| `wohnen` | die **Wohnung** | 住所 |
| `bedeuten` | die **Bedeutung** | 意义 |
| `fühlen` | die **Fühlung** | (较少,取 Gefühl) |
| `entwickeln` | die **Entwicklung** | 发展 |
| `verändern` | die **Veränderung** | 改变 |
| `entscheiden` | die **Entscheidung** | 决定 |
| `erfahren` | die **Erfahrung** | 经验 |
| `besuchen` | der **Besuch** (注意:-uch 阳,非 -ung) | 拜访 |
| `vorstellen` | die **Vorstellung** | 概念/介绍 |

> 规律强:`-ung` 一律**阴性**。例外极少。

### 2.2 `-heit / -keit / -igkeit` [A2] —— 形容词→抽象阴性名词

| 形容词 | 名词 | 义 |
|---|---|---|
| `frei` | die **Freiheit** | 自由 |
| `sicher` | die **Sicherheit** | 安全 |
| `möglich` | die **Möglichkeit** | 可能性 |
| `wichtig` | die **Wichtigkeit** | 重要性 |
| `schön` | die **Schönheit** | 美 |
| `gesund` | die **Gesundheit** | 健康 |
| `wahr` | die **Wahrheit** | 真相 |
| `einheitlich` | die **Einheit** | 单位/统一 |
| `ähnlich` | die **Ähnlichkeit** | 相似性 |
| `schwierig` | die **Schwierigkeit** | 困难 |

**分布规则**:
- `-heit`:加在**无词尾**或 `-ig/-lich/-bar` 形容词后:`Frei-heit, Wichtig-heit(→ Wichtigkeit)`。
- `-keit`:加在**带 -ig/-lich/-sam/-bar** 等词尾的形容词后:`Möglichkeit, Schwierigkeit`。
- `-igkeit`:形容词本身已带轻 -ig 时再加 keit → `Sauberkeit, Dunkelheit(←dunkel)`。

### 2.3 `-tion / -tät / -ik / -ie / -ei` [A2–B1] —— 外来阴性后缀

| 后缀 | 义 | 例 |
|---|---|---|
| `-tion` | 抽象(动) | die Information, Produktion, Nation |
| `-tät` | 性质 | die Universität, Qualität, Realität |
| `-ik` | 学科/风格 | die Musik, Politik, Physik, Grammatik |
| `-ie` | 学说/状态 | die Demokratie, Energie, Garantie |
| `-ei` | 场所/行为(本土) | die Bäckerei(面包店), Druckerei, Plauderei |
| `-ur` | 结果 | die Natur, Kultur, Rechnung… 不,Rechnung; die Literatur |

### 2.4 `-in` [A1] —— 阴性指人后缀(女性)

| 阳性 | 阴性 | 义 |
|---|---|---|
| der Lehrer | die **Lehrerin** | 女老师 |
| der Student | die **Studentin** | 女学生 |
| der Arzt | die **Ärztin**(变元音) | 女医生 |
| der Koch | die **Köchin** | 女厨师 |

**规则**:阳性指人词 + `in`(常变元音)→ 阴性。复数 `innen`:`Lehrerinnen`。

### 2.5 `-schaft` [A2] —— 阴性集合/状态名词

| 根 | 名词 | 义 |
|---|---|---|
| `Freund` | die **Freundschaft** | 友谊 |
| `Wissen` | die **Wissenschaft** | 科学 |
| `Gesell` | die **Gesellschaft** | 社会 |
| `Bruder` | die **Bruderschaft** | 兄弟会 |
| `Mann` | die **Mannschaft** | 队伍 |
| `Kenntnis` | die **Kenntnischaft**… 实为 Kenntnis | |

## 3. 产出**阳性/中性名词**的后缀

### 3.1 `-er` [A1] —— 阳性指人/工具

| 根 | 名词 | 义 |
|---|---|---|
| `lehren` | der **Lehrer** | 老师 |
| `arbeiten` | der **Arbeiter** | 工人 |
| `fahren` | der **Fahrer** | 司机 |
| `kaufen` | der **Käufer**(变元音) | 买家 |
| `Computer`(外来) | der **Computer** | 电脑 |
| `Schrank`→der **Schrank**… | (非派生) | |

**功能**:动词词干 + er = 「做…的人/工具」,也用于外来词(Computer, Recher)。

### 3.2 `-ismus / -ist` [B1] —— 阳性,外来主义/人

| 后缀 | 义 | 例 |
|---|---|---|
| `-ismus` | 主义 | der Kapitalismus, Tourismus, Realismus |
| `-ist` | …主义者 | der Kapitalist, Tourist, Artist |

### 3.3 `-or / -ant / -ent` [B1] —— 阳性外来指人

| 后缀 | 例 | 复数(n-变化!) |
|---|---|---|
| `-or` | der Professor, Autor, Direktor | Professoren, Autoren |
| `-ant` | der Passant, Elefant, Lieferant | Passanten |
| `-ent` | der Student, Präsident, Moment | Studenten |

> 这类**多为 n-变化弱名词**(见 `06-inflectional.md`)。

### 3.4 `-chen / -lein` [A1] —— 中性指小(Verkleinerung)

| 根 | 名词 | 义 |
|---|---|---|
| `Mädchen` ← Magd | das **Mädchen** | 女孩(古 Magd+-chen) |
| `Haus` | das **Häuschen**(变元音) | 小房子 |
| `Buch` | das **Büchlein** | 小册子 |
| `Tier` | das **Tierchen** | 小动物 |

**规则**:`-chen/-lein` → 一律**中性**,常**变元音**。这就是为什么 `Mädchen` 是中性。

### 3.5 `-ment` [B1] —— 中性外来

| 例 | 义 |
|---|---|
| das **Dokument** | 文件 |
| das **Element** | 元素 |
| das **Pfund**… 不,本土 | |
| das **Medikament** | 药物 |

### 3.6 `-tum` [B2] —— 中性/阳性集合

| 例 | 义 |
|---|---|
| das **Königtum** | 王权 |
| das **Eigentum** | 财产 |
| das **Altertum** | 古代 |
| der **Irrtum** | 错误(阳性例外) |

## 4. 产出**形容词**的后缀

### 4.1 `-ig` [A2] —— 名词/副→形容词(最常见)

| 根 | 形容词 |
|---|---|
| `Sonne` | **sonnig** |
| `Wolke` | **wolkig** |
| `Mut` | **mutig** |
| `Eile` | **eilig** |
| `glück` | **glücklich**(-ig+-lich 复合) |
| `fertig` | (本土) |

### 4.2 `-lich` [A2] —— 名词/副→形容词 / 副(关系)

| 根 | 形容词 |
|---|---|
| `Tag` | **täglich** |
| `Freund` | **freundlich** |
| `Ende` | **endlich** |
| `Heimat` | **heimatlich** |
| `möglich` | (已含 -lich) |
| `wirklich` | 真正的 |

**功能**:表「与…有关的」「以…方式的」,很多可兼作副词:`wirklich, täglich`。

### 4.3 `-isch` [A2] —— 国家/风格/贬义

| 根 | 形容词 |
|---|---|
| `Deutschland` | **deutsch**(无 -isch,例外);对比 **französisch, englisch** |
| `Europa` | **europäisch** |
| `Kind` | **kindisch**(幼稚,贬)/ **kindlich**(孩子气,中性) |
| `Mädchen` | **mädchenhaft** |

> `-isch` vs `-lich` 的褒贬差:`kindisch`(贬)vs `kindlich`(中)。这是细微但重要的差别。

### 4.4 `-bar` [B1] —— 动词→「可…的」(最有用!)

| 动词 | 形容词 | 义 |
|---|---|---|
| `trinken` | **trinkbar** | 可饮用的 |
| `lesen` | **lesbar** | 可读的 |
| `machen` | **machbar** | 可行的 |
| `nutzen` | **nutzbar** | 可用的 |
| `erklären` | **erklärbar** | 可解释的 |
| `sehen` | **sichtbar**(→ -bar 在 sehn 后变 sicht-,Allomorph) | 可见的 |

**功能**:相当于英语 `-able/-ible`。A2/B1 高频。

### 4.5 `-los` [B1] —— 名词→「无…的」(否定)

| 根 | 形容词 |
|---|---|
| `Arbeit` | **arbeitslos** |
| `Ende` | **endlos** |
| `Sinn` | **sinnlos** |
| `Zweifel` | **zweifellos** |
| `Schmerz` | **schmerzlos** |

### 4.6 `-haft` [B1] —— 「有…特质的」

| 根 | 形容词 |
|---|---|
| `Traum` | **traumhaft** |
| `Märchen` | **märchenhaft** |
| `Krankheit` | **krankhaft** |
| `Fehler` | **fehlerhaft** |

### 4.7 `-sam` [B2] —— 「有…倾向的」

| 根 | 形容词 |
|---|---|
| `Mühe` | **mühsam** |
| `Gewalt` | **gewaltsam** |
| `aufmerk-` | **aufmerksam** |
| `lang` | **langsam** |

## 5. 产出**动词**的后缀

### 5.1 `-ieren` [B1] —— 外来动词

| 名词/形容词 | 动词 |
|---|---|
| `Studium` | **studieren** |
| `passiv` | **passieren** |
| `Telefon` | **telefonieren** |
| `Maschine` | **maschinieren**…(罕);常用 **probieren** |
| `organis-` | **organisieren** |

**特征**:重音在**倒数第二音节**;过去分词**无 ge-**(`studiert, passiert`)。

### 5.2 `-eln / -ern` [B1] —— 本土弱动词

| 根 | 动词 | 功能 |
|---|---|---|
| `Handel` | **handeln** | 行为 |
| `sticheln` | (反复/轻微) | 反复 |
| `blitzen` | (异根) | |
| `Löffel`→löffeln | 用勺 | 工具 |
| `-ern`:`blättern`, **ändern**(←anders) | | |
| 形容词→-ern(材料):**eisern, hölzern, gläsern** | 由…制的 | |

## 6. 产出**副词/小品词**的后缀

### 6.1 `-s` [A2] —— 副

| 根 | 副 |
|---|---|
| `morgens` | 早上 |
| `abends` | 晚上 |
| `nachts` | 夜里 |
| `rechts / links` | 右/左 |
| `teils` | 部分 |

### 6.2 `-erweise` [B1] —— 副(观点)

| 形容词 | 副 | 义 |
|---|---|---|
| `glücklicherweise` | 幸运地 | |
| `interessanterweise` | 有趣地 | |
| `natürlicherweise` | 自然地 | |
| `leider`(异构) | 可惜 | |

**功能**:相当于英语 `-ly`(整句评注)。

---

## 8. 小结

- **后缀决定词性**:看到词尾就能猜词性(`-ung → 阴,-er → 阳,-chen → 中`)。
- **后缀决定词义色彩**:`-bar(可),-los(无),-haft(特质),-isch(风格)`。
- **名词后缀最规律**:背 10 个后缀,猜 80% 的抽象名词。
- **形→名转换**:`-heit/-keit/-ung` 是德语抽象名词的三驾马车。
- **动词→形转换**:`-bar` 是 A2/B1 最高回报的后缀。
