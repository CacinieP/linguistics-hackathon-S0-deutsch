# 05 · 复合词 (Komposita)

> 德语最显眼的招牌:**两个或多个词根拼成新词**。
> 复合不是加词缀(不改单个词的形态),而是**词根 + 词根 → 新概念**。规模可无限生长。

---

## 1. 复合词的本质

```
复合词 Kompositum = Bestimmungswort(限定词) + Grundwort(基础词)
                     ↑ 前半,定方向/范围     ↑ 后半,定词性与核心义
```

- **性/复数由 Grundwort(后半)决定**:`die Wanderbahn` ← Autobahn(阴)。
- **重音在 Bestimmungswort(前半)**:`AUto-bahn, KIND-er-garten`。
- 三者之间常加**连接元素 -s- / -en- / -n-**(Fugen-s/-en)。

---

## 2. 按词性组合分类

### 2.1 名词 + 名词 = 名词(最常见)[A1]

| 前(限定) | 后(基础) | 复合 | 义 | 连接元素 |
|---|---|---|---|---|
| Auto | Bahn | **die Autobahn** | 高速公路 | ∅ |
| Kinder | Garten | **der Kindergarten** | 幼儿园 | -er(原词自带) |
| Buch | Regal | **das Bücherregal** | 书架 | ∅(复变元音在限定词内) |
| Hand | Schuh | **der Handschuh** | 手套 | ∅ |
| Haus | Tür | **die Haustür** | 大门 | ∅ |
| Sonne | Blume | **die Sonnenblume** | 向日葵 | -en(Fuge) |
| Arbeit | Platz | **der Arbeitsplatz** | 工位 | -s(Fuge) |
| Wasser | Melone | **die Wassermelone** | 西瓜 | ∅ |
| Zeit | Schrift | **die Zeitschrift** | 杂志 | ∅ |
| Polizei | Wache | **die Polizeiwache** | 警察局 | ∅ |

### 2.2 形容词 + 名词 = 名词 [A2]

| 前 | 后 | 复合 | 义 |
|---|---|---|---|
| Groß | Eltern | **die Großeltern** | 祖父母 |
| Hoch | Haus | **das Hochhaus** | 高楼 |
| Klein | Kind | **das Kleinkind** | 幼儿 |
| Fremd | Wort | **das Fremdwort** | 外来词 |
| Weiß | Wein | **der Weißwein** | 白葡萄酒 |

### 2.3 动词词干 + 名词 = 名词 [A2/B1]

| 前(动词干) | 后(名词) | 复合 | 义 |
|---|---|---|---|
| Wasch | Maschine | **die Waschmaschine** | 洗衣机 |
| Fahr | Rad | **das Fahrrad** | 自行车 |
| Schreib | Tisch | **der Schreibtisch** | 书桌 |
| Bade | Zimmer | **das Badezimmer** | 浴室 |
| Wohn | Zimmer | **das Wohnzimmer** | 起居室 |
| Schlaf | Zimmer | **das Schlafzimmer** | 卧室 |
| Ess | Zimmer | **das Esszimmer** | 餐厅 |
| Brat | Pfanne | **die Bratpfanne** | 煎锅 |

> 动词词干去 -en,直接接名词:`waschen → Wasch-`。

### 2.4 介词 + 名词 = 名词/副 [B1]

| 前 | 后 | 复合 | 义 |
|---|---|---|---|
| Unter | Grund | **der Untergrund** | 地下 |
| Über | blick | **der Überblick** | 概览 |
| Vor | schrift | **die Vorschrift** | 规定 |
| Mit | arbeiter | **der Mitarbeiter** | 同事 |
| Nach |richt | **die Nachricht** | 消息 |
| Aus | druck | **der Ausdruck** | 表达 |

### 2.5 副词/数词 + 名词 [A2]

| 前 | 后 | 复合 |
|---|---|---|
| Mehr | Zweck | **Mehrzahl**(复数)/ **Mehrzweck**(多用) |
| Dritt | Rad | **das Dreirad**(三三轮)→ 实为 Zahl+名词 |
| Haupt | Sache | **die Hauptsache** | 主要 |

### 2.6 名词 + 动词 / 形容词 + 动词 = 动词(较少)[B2]

| 复合 | 义 | 备注 |
|---|---|---|
| **teilnehmen** | 参加 | teil + nehmen,可分 |
| **stattfinden** | 举行 | statt + finden,可分 |
| **kennenlernen** | 结识 | kennen + lernen,可分 |
| **spazierengehen** | 散步 | spazieren + gehen,可分 |
| **liebäugeln** | 垂涎 | liebe + äugeln,不可分 |

## 3. 连接元素 (Fugenelement)

复合时,两词之间常插入**连接字母**,无实义,只为发音顺:

| Fuge | 例 | 规律 |
|---|---|---|
| **∅** | Autobahn, Buchregal | 最常见 |
| **-s-** | Arbeitsplatz, Zeitungsartikel | 多在以 -ung/-heit/-keit/-ion 结尾或为「关系标记」 |
| **-en-** | Sonnenblume, Schlaganfall | 多在阴性名词后(复数 -en) |
| **-n-** | Schlangenmenschen… | 阴性 -e 词后 |

> Fuge 不是语素,是**语音润滑**——但要背对,否则拼错。

---

## 4. 复合词的语义关系(限定类型)

前半(Bestimmungswort)对后半(Grundwort)的关系有多种:

| 关系 | 例 | 解读 |
|---|---|---|
| **材料** | Goldring | 金(做的)戒指 |
| **目的** | Waschmaschine | 用来洗的机器 |
| **地点** | Stadtbibliothek | 城市里的图书馆 |
| **时间** | Nachtfalter | 夜里的飞蛾 |
| **相似** | Goldfisch | 金色的鱼(非金做) |
| **反义** | Halbgott | 半神 |
| **整体-部分** | Blattspitze | 叶(的)尖 |

## 5. 嵌套复合(长词)[B1–C1]

德语可无限嵌套。**长词不可怕**,从右(基础)往左(限定)拆:

### 5.1 三段

| 词 | 拆解 | 义 |
|---|---|---|
| **Donaudampfschifffahrt** | Donau + Dampf + Schiff + Fahrt | 多瑙河蒸汽船航行 |
| **Kühlschranktür** | Kühl + Schrank + Tür | 冰箱门 |
| **Arbeitsamtsgesetz** | Arbeit + Amt + Gesetz | 劳工局法 |
| **Geschwindigkeitsbegrenzung** | Geschwindigkeits + Begrenzung | 限速 |

### 5.2 C2 级嵌套

**Nahrungsmittelunverträglichkeit**(食物不耐受):
```
Nahrung + s + Mittel + Un + ver + träglich + keit
食     +     品      + 不  + 容    + 的    + 性
```
拆完 8 个语素,但语义透明:食物 + 制品 + 不 + 能忍 + 的 + 性质。

> 拆长词口诀:**从右往左,每切一段问「这是修饰下一段的吗?」**。

---

## 6. 复合 vs 派生:一张对比

| | 复合 Komposition | 派生 Derivation |
|---|---|---|
| 零件 | 词根 + 词根 | 词根 + 词缀 |
| 词缀? | 无 | 有(前缀/后缀) |
| 词性 | 由后半决定 | 由后缀决定 |
| 例 | Autobahn | Un-abhängig-keit |
| 规模 | 可无限长 | 有限组合 |

---

## 7. 小结

- 复合 = **限定词 + 基础词**,基础词定词性,限定词定意义。
- **长词 = 多次复合的嵌套**,从右往左拆即可。
- **Fuge**(-s/-en)是语音润滑,不是语素。
- 德语「能造无限长的词」就是靠复合——这正是为什么词汇量看似巨大,实则零件有限。
