# 06 · 屈折词缀 (Flexionsmorpheme)

> 屈折词缀只**改变词的语法形态**(格、人称、时态、数),**不改词性、不改核心词义**。
> 与派生词缀的本质区别:**派生造新词,屈折变同一个词的形态**。

---

## 1. 屈折 vs 派生 一表清

| | 屈折 Flexion | 派生 Derivation |
|---|---|---|
| 作用 | 变格/变位/比较 | 造新词 |
| 词性 | 不变 | 改变 |
| 词典收录 | 同一条目 | 单独条目 |
| 例 | Tag → Tage, Tag, Tage;gehen → gehe | Tag → täglich;gehen → Gehweg |
| 词缀位置 | 多在词尾 | 前缀/后缀 |

> 一个词常**先派生后屈折**:`Schön-heit`(派生)→ `Schönheiten`(复数,屈折)。

---

## 2. 名词屈折 (Nominalflexion)

### 2.1 数 (Numerus): 单 → 复

| 类型 | 词尾 | 例 |
|---|---|---|
| 加 -e | -e | Wort → Wörter(常带变元音) |
| 加 -er | -er | Buch → Bücher(变元音) |
| 加 -n/-en | -n/-en | Frau → Frauen, Zeitung → Zeitungen |
| 加 -s | -s | Auto → Autos(外来/缩略) |
| 零标记 | ∅+变元音 | Vater → Väter |

### 2.2 格 (Kasus): 四格词尾

详见 `02-morphology/README.md` §1.3。这里只列**词缀层面**:

| 格 | 定冠词词尾 | 不定冠词词尾 | 无冠词形容词词尾 |
|---|---|---|---|
| Nom | -r/-s/-e | ein/eine | -er/-es/-e |
| Akk | -n/-s/-e | einen/ein/eine | -en/-es/-e |
| Dat | -m/-m/-r/-n | einem/einem/einer | -em/-em/-er/-en |
| Gen | -s/-s/-r/-r | eines/eines/einer | -en/-en/-er/-er |

### 2.3 n-变化 (n-Deklination) —— 阳性为主

某些阳性名词在**非 Nom 单数全部加 -(e)n**:

| Nom | 其它格 | 词缀变化 |
|---|---|---|
| der Student | des/den/dem **Studenten** | + -en |
| der Herr | des **Herrn**, dem **Herrn** | + -n(词干也变) |
| der Name | des **Namens** | + -ens(Gen 加 s) |
| der Junge | den **Jungen** | + -n |

> n-变化的 `-n/-en` 是**屈折词缀**(只标格,不改词性)。

### 2.4 Genitiv -s

普通阳中名词 Gen 加 `-(e)s`:
- `des Tages, des Buches, des Autos`
- 这里 `-s` 也是屈折词缀。

## 3. 动词屈折 (Verbalflexion)

### 3.1 人称/数词尾(现在时) [A1]

| 人称 | 词尾(规则) |
|---|---|
| ich | -e |
| du | -st |
| er/sie/es | -t |
| wir | -en |
| ihr | -t |
| sie/Sie | -en |

> 这些 `-e/-st/-t/-en` 就是**屈折词缀**,标人称和数。

### 3.2 强变化:词根元音交替(Ablaut) [A2]

强变化动词在 du/er 单数(及过去时/分词)**词干元音变**:

| 词根 | 现在时交替 | 过去时(第二态) | 分词(第三态) |
|---|---|---|---|
| `sprech-` | a→i:sprichst/spricht | sprach | gesproch-en |
| `geb-` | a→i:gibst/gibt | gab | gegeb-en |
| `fahr-` | a→ä:fährst/fährt | fuhr | gefahr-en |
| `seh-` | e→ie:siehst/sieht | sah | geseh-en |
| `find-` | (不变) | fand | gefund-en |

> **元音交替(Ablaut)是「内部屈折」**——不用词缀,改词根本身的元音来表语法变化。这是日耳曼语族的古老特征。

### 3.3 过去分词词缀 ge- … -en/-t [A2]

| 类型 | 构成 | 例 |
|---|---|---|
| 弱动词 | **ge-** + 词干 + **-(e)t** | ge-mach-t, ge-lern-t |
| 强动词 | **ge-** + 变化词干 + **-en** | ge-trunk-en, ge-seh-en |
| 不可分前缀词 | **无 ge-** | ver-stand-en, be-zahl-t |
| -ieren 外来词 | **无 ge-** + -t | studier-t, passier-t |
| 可分前缀词 | 前缀 + **ge-** + 词干 + -en/-t | auf-ge-stand-en |

> `ge-`(前缀)和 `-t/-en`(后缀)在这里都是**屈折词缀**——标「过去分词」这个语法范畴。

### 3.4 过去时词缀 -te [A2]

弱动词过去时 = 词干 + **-te** + 人称词尾:
- `mach-te, lern-te, spiel-te`

> `-te` 是弱动词过去时的**屈折标记**。

### 3.5 虚拟式词缀 [B2]

- **Konjunktiv II**:强动词词干 + 变元音 + `-e` + 词尾:`fähre, gäbe, käme`。
- 这里的变元音 + 词尾都是屈折。

### 3.6 命令式 [A1]

命令式 = 词干(去词尾,2单):
- `geh!, mach!, sprich!`(强变化取变元音词干)
- 无词缀,但**形态变化本身**是屈折(去掉词尾)。

## 4. 形容词屈折 (Adjektivflexion)

### 4.1 定语形容词词尾(三套)[A2]

详见 `02-morphology/README.md` §4.1。词尾(`-e/-en/-er/-es/-em`)是屈折词缀,标格/性/数,有三套范式:
- 定冠词后(弱):多 -e/-en
- 不定冠词后(混合)
- 无冠词(强)

### 4.2 比较等级 [A2]

| 级 | 词缀 | 例 |
|---|---|---|
| 原级 | ∅ | klein |
| 比较级 | **-er** | klein-er |
| 最高级 | **-(e)st** | klein-st |

> `-er` / `-st` 是**屈折词缀**。强变化词根同时**变元音**:`alt→ält-er, groß→größ-er`(内部屈折)。

### 4.3 `am + 最高级 + -en` [A2]

`am schönsten, am besten` —— `-en` 也是屈折词尾(形容词名词化/副词化的标记)。

## 5. 代词屈折

### 5.1 人称代词变格 [A1]

| Nom | Akk | Dat |
|---|---|---|
| ich | mich | mir |
| er | ihn | ihm |
| sie | sie | ihr |
| wir | uns | uns |

> 人称代词的格变化**内部屈折**(改词根本身,如 `er→ihn→ihm`)。

### 5.2 反身代词

`sich`(三单/三复),其它同人称代词的 Akk/Dat。

### 5.3 冠词/物主的屈折

`der→den→dem→des`,`mein→meinen→meinem→meines` —— 全部是屈折。

## 6. 屈折词缀总览表

| 词类 | 范畴 | 屈折词缀 | 例 |
|---|---|---|---|
| 名词 | 数 | -e/-er/-n/-en/-s/∅ | Wörter, Bücher |
| 名词 | 格(Gen) | -(e)s | des Tages |
| 名词 | 格(n-变化) | -(e)n | den Studenten |
| 动词 | 人称/数 | -e/-st/-t/-en/-n | mache, machst |
| 动词 | 过去时 | -te | machte |
| 动词 | 过去分词 | ge-…-t / ge-…-en | gemacht, gesehen |
| 动词 | 内部屈折 | 元音交替(Ablaut) | sprechen→spricht |
| 动词 | 命令式 | -∅(去尾) | geh! |
| 形容词 | 格/性/数 | -e/-en/-er/-es/-em | der gute Mann |
| 形容词 | 比较级 | -er | kleiner |
| 形容词 | 最高级 | -(e)st | kleinste |
| 代词 | 格 | 内部屈折 | er→ihn→ihm |

---

## 7. 小结

- **屈折 = 同一个词换形态**,词性不变,词义不变。
- 屈折词缀**高度规律、封闭有限**,是德语语法的「齿轮」。
- 德语屈折的两大杀手锏:**词尾变化**(格/人称)+ **内部元音交替**(强变化)。
- 学屈折词缀 = 学语法表,详见 `02-morphology/`(形态学补全)。
